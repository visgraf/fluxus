# fluxus

An immersive 3D puzzle-adventure inspired by M.C. Escher’s Print Gallery and the mathematics of Möbius transformations on the Riemann Sphere. Players explore recursive worlds connected through impossible portals, conformal distortions, and non-Euclidean spaces where environments continuously fold, scale, and transform into themselves. Blending surreal atmosphere, mathematical art, and spatial gameplay, the project turns recursive geometry into an interactive experience of infinite worlds within worlds.
